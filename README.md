# PromoGen — Утилита генерации и валидации промокодов

## Структура проекта

```
promogen/
├── index.html   — разметка страницы
├── style.css    — все стили (CSS-переменные, компоненты, адаптив)
├── app.js       — вся логика (генерация, валидация, экспорт, UI)
└── README.md
```

## Запуск

Откройте `index.html` в любом браузере — никакой сборки и зависимостей не требуется.

Или через локальный сервер:
```bash
npx serve .
# → http://localhost:3000
```

## Возможности

| Функция | Описание |
|---------|----------|
| 🎲 Генератор | Настраиваемые правила: тип, длина, префикс, алфавит |
| 🔍 Валидатор | Проверка кода + инкремент счётчика использований |
| 📋 Копирование | Один клик — код в буфер обмена |
| 📥 Экспорт | Выгрузка всех кодов в CSV (с BOM для Excel) |
| 🗂 Фильтрация | Вкладки: все / активные / использованные |
| 📊 Статистика | Live-счётчики в хедере |

## Нетривиальная логика (на стороне клиента)

1. **Генератор с гарантией уникальности** — при генерации каждый новый код проверяется через `Set` уже существующих кодов; коллизии отбрасываются. Лимит попыток предотвращает бесконечный цикл на малых алфавитах (`app.js` → `generateCodes`).

2. **Конфигурируемый алфавит** — опция «исключить похожие символы» убирает `0 O 1 I l`, чтобы промокод можно было безошибочно прочитать вслух или с экрана (`app.js` → `buildAlphabet`).

3. **Валидация со счётчиком использований** — у каждого кода есть поля `usedCount` и `maxUses`. Валидатор проверяет существование → исчерпанность → применяет код (инкрементирует счётчик). Один и тот же код нельзя использовать сверх лимита (`app.js` → `validateCode`).

4. **Экспорт CSV с BOM** — добавляется `\uFEFF` для корректного открытия в Microsoft Excel, иначе кириллица отображается как мусор (`app.js` → `exportCSV`).

## Описание работы с Claude Code

### Что использовалось

Утилита разработана с применением Claude Code (claude.ai) как основного инструмента — в режиме прямого диалога с моделью, без запуска CLI.

### Ключевые промпты

**Промпт 1 — постановка задачи:**
> «Разработай веб-утилиту для генерации и проверки промокодов. Одна HTML-страница без зависимостей. Требования: настройка типа кода (скидка %, фикс.скидка, бесплатная доставка, пробный период), префикс, длина, количество, алфавит (буквы/цифры, исключение похожих символов). Валидатор должен проверять код и инкрементировать счётчик использований. Экспорт в CSV. Тёмная тема, профессиональный UI.»

**Промпт 2 — уточнение логики:**
> «Добавь лимит использований на код — поле maxUses. Валидатор должен показывать ошибку если лимит исчерпан, и обновлять счётчик при успешной проверке.»

**Промпт 3 — UX:**
> «Добавь вкладки Все / Активные / Использованные в список кодов. Статистику (активно, использовано, всего) — в хедер.»

**Промпт 4 — рефакторинг структуры:**
> «Раздели проект на три отдельных файла: index.html, style.css, app.js. Код должен быть читаемым и структурированным.»

### Что AI сделал сразу

- Полную структуру HTML/CSS/JS со `state`-объектом и функциями `render`/`update`
- Логику генератора с конфигурируемым алфавитом
- Дизайн-систему (CSS-переменные, тёмная тема, типографика)
- Базовый валидатор и toast-уведомления
- Разбивку на три файла с корректными ссылками `<link>` и `<script>`

### Что пришлось доработать вручную

- **BOM в CSV-экспорте** — AI добавил экспорт, но не учёл, что Excel не воспринимает UTF-8 без BOM. Добавлен вручную (`\uFEFF`).
- **Защита от бесконечного цикла** — при маленьком алфавите и большом количестве кодов генератор мог зависнуть. Добавлен лимит `attempts < count * 20`.
- **CSS-деталь с `opacity` на disabled-поле** — AI не скрывал поле «значение» при типе «бесплатная доставка». Добавлен обработчик и визуальное затемнение.
- **Scroll на списке кодов** — при большом количестве кодов список уходил за экран. Добавлен `max-height` + кастомный скроллбар.
